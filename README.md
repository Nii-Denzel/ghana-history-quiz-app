# How Well Do You Know Your Country? – Quiz App

A simple interactive quiz game built with **HTML, CSS, and JavaScript**.  
The app tests your knowledge of Ghana with fun multiple-choice questions.  

## Key Features
- 100+ Ghana-themed questions (history, geography, culture, sports, etc.)  
- Randomly selects 10 questions per round  
- Shows immediate feedback on correct/wrong answers  
- Simple, colorful UI suitable for kids and learners  

## How to Run
1. Clone this repository:
   git clone https://github.com/Nii-Denzel/ghana-history-quiz-app.git
2. Open the project folder.
3. Double-click index.html to open it in your browser.
